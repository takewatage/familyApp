## 1. 概要

本ドキュメントは、Laravelアプリケーションに追加する家計簿機能のデータベース設計を定義します。家族単位での支出管理、予算管理、データ可視化を実現するために必要なテーブル構造を記載しています。

### 設計方針

- 家族単位でのデータ分離（`family_id` による絞り込み）
- 論理削除の採用（`is_active` フラグ）
- 拡張性を考慮した正規化設計
- Laravel の Eloquent ORM に適した命名規則（スネークケース、複数形テーブル名）
- タイムスタンプカラム（`created_at`, `updated_at`）の標準装備

### 前提条件

- 既存の `users` テーブルが存在すること
- MySQL 8.0 以上 または MariaDB 10.5 以上
- 文字コード: utf8mb4

## 3. テーブル定義

### 3.1 families（家族）

家族グループを管理するテーブル。複数ユーザーで家計簿を共有するための単位。

#### カラム定義

| カラム名 | データ型 | 制約 | 説明 |
|---------|---------|------|------|
| id | BIGINT UNSIGNED | PRIMARY KEY, AUTO_INCREMENT | 家族ID（主キー） |
| name | VARCHAR(100) | NOT NULL | 家族名（例：山田家） |
| invite_code | VARCHAR(32) | UNIQUE, NOT NULL | 招待コード（家族メンバー追加用） |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新日時 |

#### インデックス

| インデックス名 | カラム | 種別 |
|--------------|--------|------|
| idx_families_invite_code | invite_code | UNIQUE |

---

### 3.2 family_members（家族メンバー）

ユーザーと家族の関連を管理する中間テーブル。一人のユーザーは一つの家族に所属。

#### カラム定義

| カラム名 | データ型 | 制約 | 説明 |
|---------|---------|------|------|
| id | BIGINT UNSIGNED | PRIMARY KEY, AUTO_INCREMENT | メンバーID（主キー） |
| family_id | BIGINT UNSIGNED | NOT NULL, FOREIGN KEY | 所属する家族ID（FK: families.id） |
| user_id | BIGINT UNSIGNED | NOT NULL, UNIQUE, FOREIGN KEY | ユーザーID（FK: users.id） |
| nickname | VARCHAR(50) | NOT NULL | 家族内での呼び名（例：父、母、太郎） |
| role | ENUM('admin', 'member') | NOT NULL, DEFAULT 'member' | 役割：admin（管理者）/ member（一般） |
| color | VARCHAR(7) | NOT NULL, DEFAULT '#3B82F6' | 表示色（HEXカラーコード） |
| created_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新日時 |

#### インデックス

| インデックス名 | カラム | 種別 |
|--------------|--------|------|
| idx_family_members_family_id | family_id | INDEX |
| idx_family_members_user_id | user_id | UNIQUE |
