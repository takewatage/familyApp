# テスト手順書 - 家族設定機能

## 概要

家族設定変更・メンバー管理・家族切り替えの各機能を手動テストで確認します。

### テスト方針

**人間が実際に操作して確認することを最優先とします。**

- 手動テスト: すべての機能要件・受け入れ条件について、人間が操作手順で確認する
- 自動テスト: 手動で確認が困難な項目（権限制御の境界値など）に限定する

## 前提条件

- 開発サーバーが起動済みであること（`sail up -d` → `sail yarn dev`）
- テスト用ユーザーA（オーナー）でログインできること
- テスト用ユーザーB（メンバー）が同一家族に所属していること
- 仮想ユーザーが1件以上登録されていること

---

## 手動テスト

### ケース 1: マイページに家族設定メニューが表示される

**対応要件:** F-010, F-011, F-012

**手順:**

1. ユーザーAでログインする
2. マイページを開く

**期待結果:**

- 「家族設定」セクションに「家族設定変更」「メンバー管理」「家族切り替え」の3項目が表示される

**確認結果:**

- [ ] OK / NG

---

### ケース 2: 家族設定変更（オーナー）

**対応要件:** F-010

**手順:**

1. ユーザーA（オーナー）でマイページ → 家族設定変更を開く
2. 家族名を変更して「保存」をタップする
3. 再度ページを開いて変更が反映されているか確認する

**期待結果:**

- 保存後にスナックバーで成功通知が表示される
- 変更した家族名が反映されている

**確認結果:**

- [ ] OK / NG

---

### ケース 3: 家族設定変更（メンバーは閲覧のみ）

**対応要件:** F-010

**手順:**

1. ユーザーB（メンバー）でマイページ → 家族設定変更を開く

**期待結果:**

- フォームが読み取り専用で表示される
- 「保存」ボタンが表示されない

**確認結果:**

- [ ] OK / NG

---

### ケース 4: 家族コード再生成

**対応要件:** F-010

**手順:**

1. ユーザーA（オーナー）で家族設定変更ページを開く
2. 「再生成」ボタンをタップする
3. 確認ダイアログで有効期限（例: 24時間）を選択して実行する

**期待結果:**

- 新しいコードが表示される
- 有効期限が設定した日時で表示される

**確認結果:**

- [ ] OK / NG

---

### ケース 5: メンバー一覧表示と招待コードのコピー

**対応要件:** F-011

**手順:**

1. マイページ → メンバー管理を開く
2. 招待コードの「コピー」をタップする

**期待結果:**

- 実メンバー一覧に名前・アバター・ロールが表示される
- クリップボードに招待コードがコピーされる

**確認結果:**

- [ ] OK / NG

---

### ケース 6: メンバー除名（オーナーのみ）

**対応要件:** F-011

**手順:**

1. ユーザーA（オーナー）でメンバー管理を開く
2. ユーザーB の「除名」ボタンをタップする
3. 確認して除名を実行する

**期待結果:**

- ユーザーBがメンバー一覧から消える
- オーナー自身の行には「除名」ボタンが表示されない

**確認結果:**

- [ ] OK / NG

---

### ケース 7: 仮想ユーザーの追加 - ダイアログレイアウト確認

**対応要件:** F-011

**手順:**

1. メンバー管理ページを開く
2. 「+ 仮想メンバーを追加」をタップしてダイアログを開く
3. ダイアログ内の追加ボタンの表示を確認する

**期待結果:**

- 追加ボタンがダイアログ内に収まり、レイアウトが崩れていない
- 名前を入力して「保存」をタップすると仮想ユーザーが追加される

**確認結果:**

- [ ] OK / NG

---

### ケース 8: 仮想ユーザーの編集

**対応要件:** F-011

**手順:**

1. メンバー管理ページで仮想ユーザーの「編集」をタップする
2. 名前を変更して「保存」をタップする

**期待結果:**

- 変更した名前が一覧に反映される

**確認結果:**

- [ ] OK / NG

---

### ケース 9: 仮想ユーザーの削除 - 確認ダイアログ

**対応要件:** F-011

**手順:**

1. メンバー管理ページで仮想ユーザーの「削除」をタップする
2. 確認ダイアログが表示されることを確認する
3. 「キャンセル」をタップしてダイアログを閉じる
4. 再度「削除」をタップして確認ダイアログで「削除」を実行する

**期待結果:**

- 削除前に確認ダイアログが表示される
- キャンセル時は削除されない
- 削除実行後に仮想ユーザーが一覧から消える

**確認結果:**

- [ ] OK / NG

---

### ケース 10: 家族切り替え

**対応要件:** F-012

**手順:**

1. 複数の家族グループに所属しているユーザーでログインする
2. マイページ → 家族切り替えを開く
3. 現在と異なる家族グループをタップする

**期待結果:**

- 所属している家族グループ一覧が表示される
- 現在のアクティブ家族にチェックマークが付いている
- 選択後にホーム画面へ遷移する

**確認結果:**

- [ ] OK / NG

## 回帰テスト

既存機能への影響がないことを確認します。

- [ ] マイページの既存情報（名前・アバター・誕生日）が正常に表示・編集できる
- [ ] タスク管理画面が正常に動作する
- [ ] ユーザー個別設定（テーマ・テーマカラー）が正常に動作する

- [ ] 手動テストの全ケースが OK
- [ ] エッジケースの確認が完了
