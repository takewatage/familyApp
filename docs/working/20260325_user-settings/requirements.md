# 要件定義書 - ユーザー個別設定編集機能

## 概要

マイページからユーザー個人の設定を編集・保存できる機能を追加する。
設定値は `users` テーブルの JSON カラム（`settings`）に保存し、ユーザーごとに独立した設定として管理する。

## 背景・目的

現在のマイページはプロフィール（名前・アバター・誕生日）の編集のみに対応している。
ユーザーごとに好みの操作感・表示設定を持てるようにすることで、UX を向上させる。
設定値を JSON カラム1つに集約することで、将来的な設定項目の追加にもスキーマ変更なしで対応できる。

## 要件一覧

### 機能要件

#### F-1: ユーザー設定の表示

- **説明**: マイページに「設定」セクションを追加し、現在の設定値を表示する
- **受け入れ条件**:
  - [ ] マイページに設定セクションが表示される
  - [ ] 各設定項目の現在値が表示される
  - [ ] 未設定（初回）の場合はデフォルト値が表示される

#### F-2: ユーザー設定の編集・保存

- **説明**: 設定編集フォームから設定を変更し、保存できる
- **受け入れ条件**:
  - [ ] 設定編集ダイアログ / フォームから各設定項目を変更できる
  - [ ] 保存ボタン押下で API が呼ばれ、設定が永続化される
  - [ ] 保存成功時にスナックバーで通知が表示される
  - [ ] 保存失敗時にスナックバーでエラーが表示される

#### F-3: 設定項目

今回対応する設定項目は以下の1項目のみ（今後順次追加予定）。

| 設定キー  | 表示名 | 型     | デフォルト値   | 選択肢 / 値の範囲                       |
|---------|-------|--------|------------|---------------------------------------|
| `theme` | テーマ | string | `"system"` | `"light"` / `"dark"` / `"system"` |

- **受け入れ条件**:
  - [ ] `theme` をセレクトで選択できる（ライト / ダーク / システム設定）

### 非機能要件

- **パフォーマンス**: 設定保存の API レスポンスは 1 秒以内
- **セキュリティ**: 認証済みユーザーのみが自身の設定を変更できる（他ユーザーの設定は変更不可）
- **保守性**: JSON カラムに保存することで、設定項目の追加時にマイグレーション不要

## スコープ

### 対象

- `users` テーブルへの `settings` JSON カラム追加
- マイページの設定セクション UI
- 設定の保存 API（`/mypage/settings` POST）

### 対象外

- 設定値をリアルタイム同期（WebSocket）で他端末に反映すること
- 管理者による設定の一括変更
- 設定のエクスポート / インポート
