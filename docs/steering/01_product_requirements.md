# プロダクト要求定義書（PRD）

## 1. プロダクト概要

### 1.1 プロダクト名

Family App

### 1.2 目的

家族で必要なアプリを一つにまとめ、家族メンバー全員が共有・管理できるようにする。
バラバラに存在するタスク管理・家計・買い物リストなど、家族生活に必要なツールを一元化し、家族間の情報共有とコミュニケーションを円滑にする。

### 1.3 対象ユーザー

- **家族メンバー（エンドユーザー）**: 夫婦・親子など、同一家族グループを形成するメンバー全員が対象。スマートフォンやPCのWebブラウザから利用する。

### 1.4 主要な価値提案

- 家族で使うアプリを一つに集約することで、複数のアプリを行き来する手間を省く
- リアルタイム同期により、家族メンバー全員が最新の状態を常に把握できる
- タスク・Dok（日用品価格管理）など複数の機能を家族単位で共有管理できる

### 2.2 各機能の詳細

#### F-001: ユーザー認証

- **概要**: 招待URL経由のユーザー登録・ログイン・パスワードリセット
- **ユースケース**: 招待URLを受け取った新規ユーザーが登録し、家族グループに参加する
- **受け入れ条件**:
    - [x] 招待URL（`/join/{code}`）経由でのみ新規登録できる（直接 `/register` アクセスは不可）
    - [x] 登録時に名前・メール・パスワード・生年月日（任意）・アバター（任意）を入力できる
    - [x] 登録完了と同時に対象の家族へ自動参加する
    - [x] ログイン・ログアウトができる
    - [x] パスワードリセットメールが送信される

#### F-002: 家族グループ管理

- **概要**: 家族グループを作成し、招待コードで他のメンバーを招待できる
- **ユースケース**: 家族の一人がグループを作成し、コードを共有して家族全員が参加する
- **受け入れ条件**:
    - [x] 家族グループを作成できる
    - [x] 8文字のユニークコードが生成される
    - [x] コードを使って家族に参加できる
    - [x] 最大メンバー数が設定できる

#### F-003: タスク管理

- **概要**: 家族共有のタスクを作成・管理する
- **ユースケース**: 家族メンバーが家事タスクを登録し、完了したら消し込む
- **受け入れ条件**:
    - [x] タスクを作成・編集・削除できる
    - [x] タスクに色・メモを設定できる
    - [x] タスクを完了・未完了に切り替えられる
    - [x] ドラッグ＆ドロップで並び替えができる
    - [x] 完了タスクを一括削除できる（7日以内）
    - [x] リアルタイムで他のメンバーの操作が反映される

#### F-004: カテゴリー管理

- **概要**: タスクをカテゴリー別に分類して管理する
- **ユースケース**: 「家事」「育児」「買い物」など用途別にカテゴリーを作成してタスクを整理する
- **受け入れ条件**:
    - [x] カテゴリーを作成・編集・削除できる
    - [x] ドラッグ＆ドロップで並び替えができる

#### F-006: マイページ

- **概要**: ユーザーが自身のプロフィールを管理する
- **ユースケース**: ユーザーが名前・アバター画像・誕生日を設定・更新する
- **受け入れ条件**:
    - [x] 名前を変更できる
    - [x] アバター画像をアップロードできる
    - [x] 誕生日を設定できる

#### F-009: ユーザー個別設定

- **概要**: マイページからユーザー個人の設定（テーマ・テーマカラープリセット）を編集・保存する
- **ユースケース**: ユーザーが好みのテーマ（ライト/ダーク/システム）とプライマリー・セカンダリーカラーのプリセットを選択して保存する
- **受け入れ条件**:
    - [x] マイページに設定セクションが表示される
    - [x] テーマ（ライト / ダーク / システム設定）をセレクトで変更できる
    - [x] 選択したテーマが即時に画面に反映される（`HandleInertiaRequests` で全ページに共有 → `useAppTheme` で適用）
    - [x] テーマカラーを7プリセットのカードUIから選択できる（pink / sunset / ocean / forest / lavender / autumn / midnight）
    - [x] 各テーマカードにプライマリー色・セカンダリー色の2色プレビューが表示される
    - [x] 選択したテーマカラーのプライマリー・セカンダリー両方が即時に画面に反映される
    - [x] 保存成功時にスナックバーで通知が表示される
    - [x] 保存失敗時にスナックバーでエラーが表示される
    - [x] 設定ページにアプリショートカット設定（F-013）への遷移リンクが表示される

#### F-013: フッターナビゲーション

- **概要**: 認証済みページの下部に固定フッターを表示する。表示するアプリはユーザーが個別に設定できる
- **ユースケース**: ユーザーがよく使うアプリをフッターに登録し、素早くページ遷移できる
- **受け入れ条件**:
    - [x] 認証済みページの下部にフッターナビゲーションが表示される（一部ページを除く）
    - [x] フッターのアプリアイコンをタップするとそのページへ遷移する
    - [x] 現在表示中のページのアイコン・テキストがプライマリカラーでハイライトされる
    - [x] Dok ページではフッターを非表示にする（高さ計算が特殊なため）
    - [x] アプリショートカット設定ページでフッターに表示するアプリを追加・削除・並び替えできる
    - [x] ホームは必須（削除不可）、その他のアプリは任意
    - [x] 設定はユーザー個別に保存される（`users.settings.footer_items`）
    - [x] 設定変更後のフッターに即座に反映される

#### F-010: 家族設定変更

- **概要**: 家族グループの基本情報を変更する（オーナーのみ）
- **ユースケース**: オーナーが家族名を変更したり、招待コードを再生成して安全性を高める
- **受け入れ条件**:
    - [x] 家族名を変更できる（オーナーのみ）
    - [x] 最大メンバー数を変更できる（オーナーのみ）
    - [x] 家族コードを再生成できる（有効期限：無期限・24時間・7日間・カスタム）
    - [x] オーナー以外は閲覧のみ（フォーム読み取り専用）

#### F-011: メンバー管理

- **概要**: 家族グループの実ユーザーと仮想ユーザーを管理する
- **ユースケース**: 家族を招待したり、アプリを使わない家族（子どもなど）を仮想ユーザーとして登録してタスクに割り当てる
- **受け入れ条件**:
    - [x] 実メンバー一覧（名前・アバター・ロール）を表示できる
    - [x] メンバーを除名できる（オーナーのみ、自分自身は不可）
    - [x] 招待ボタンからボトムシートを開き、ロール（保護者・子ども・メンバー）を選んで招待できる
    - [x] 招待メッセージ（案内文＋URL）をクリップボードにコピーして LINE 等で共有できる
    - [x] 招待URLのQRコードを表示してその場でスキャン招待できる
    - [x] 仮想ユーザーを追加・編集・削除できる
    - [x] 仮想ユーザーにアバター画像を設定できる（任意）

#### F-012: 家族切り替え

- **概要**: 複数の家族グループに所属している場合に、操作対象の家族を切り替える
- **ユースケース**: 実家と自分の家族など、複数の家族に所属しているユーザーが用途に応じて切り替える
- **受け入れ条件**:
    - [x] 所属している家族グループ一覧を表示できる
    - [x] 選択した家族をアクティブ家族に切り替えられる
    - [x] 切り替え後にホーム画面へ遷移する

#### F-008: Dok（日用品価格管理）

- **概要**: 日用品や買い物の価格を記録・計算する機能
- **ユースケース**: 日用品の価格を記録しておき、買い物時に価格を比較・計算する
- **受け入れ条件**:
    - [ ] 日用品の価格を登録・更新できる
    - [ ] 価格計算機能が使える

## 3. 非機能要件

### 3.1 パフォーマンス

- Webブラウザで快適に動作すること（レスポンス 2秒以内）
- Pusher を使ったリアルタイム更新が遅延なく反映されること

### 3.2 セキュリティ

- 認証済みユーザーのみがアプリ機能にアクセスできること
- 家族グループのデータは同一グループメンバーのみがアクセスできること
- パスワードは bcrypt でハッシュ化して保存すること
- 招待URLのロールパラメータはサーバー署名（`URL::signedRoute()`）で保護し、クライアントによる改ざんを防止すること

### 3.3 可用性

- Webブラウザ（PC・スマートフォン）から利用できること
- Vuetify による レスポンシブデザイン対応
- PWAで正しく表示されること

## 4. スコープ

### 4.1 対象

- Webアプリケーション（ブラウザ経由）
- 家族グループ機能を持つすべての機能
- PWA

### 4.2 対象外

- ネイティブモバイルアプリ（iOS/Android）
- 外部サービス連携（Google Calendar、LINE 等）
- 課金・サブスクリプション機能
