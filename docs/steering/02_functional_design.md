## 2. 各画面・機能の詳細

### S-000: 共通レイアウト

#### 概要

認証済みユーザー向けの統一レイアウト。全ページで共通のヘッダーとサイドメニューを提供する。

#### 構成要素

- **Layouts/AuthenticatedLayout.vue**: 認証済みページの統一レイアウト（旧 DokLayout を統合）
- **Components/Family/InviteBottomSheet.vue**: サイドメニューから開く招待ボトムシート

#### ヘッダー

- 左端: ハンバーガーメニューアイコン → サイドメニュー開閉
- 右端: ログインユーザーのアバターアイコン → タップでマイページへ遷移（画像未設定時はデフォルトアイコン）

#### サイドメニュー（ドロワー）

- コンテンツの上にオーバーレイ表示（`temporary`）、横幅は画面の90%
- 最上部: 家族アイコン + 現在の家族名（共有プロパティ `currentFamily` から取得）
- 招待ボタン: `InviteBottomSheet` を開いてメンバー招待（共有プロパティ `inviteUrls` を使用）
- アプリ一覧: どっちがお得カネ（`/dok`）・TODOリスト（`/tasks`）

#### フッターナビゲーション

- `v-bottom-navigation`（Vuetify）で実装。アクティブ項目はプライマリカラーで表示
- 表示アプリは `userSettings.footerItems`（共有プロパティ）から `FOOTER_APPS` 定数を解決して表示
- 現在のURLと `app.route` の前方一致でアクティブ項目を算出
- Dok ページ（`/dok`）では `FOOTER_HIDDEN_ROUTES` により非表示
- 利用可能なアプリは `Constants/footerApps.ts` の `FOOTER_APPS` で管理。新機能追加時はここに追記する

#### 共有プロパティ（HandleInertiaRequests）

| プロパティ | 型 | 説明 |
|---|---|---|
| `auth.user` | `UserData`（`avatar` アクセサ付き） | ログインユーザー情報（アバター画像URL含む） |
| `userSettings` | `{ theme, themeName, footerItems }` | テーマ・テーマカラープリセット・フッター設定 |
| `currentFamily` | `{ id, name } \| null` | アクティブ家族情報 |
| `inviteUrls` | `Record<string, string>` | ロール別署名付き招待URL（`InviteUrlService` 経由） |

### S-002: 新規登録画面

#### 概要

招待URL（S-014）経由でのみアクセス可能なユーザー登録画面。登録と同時に家族へ自動参加する。

#### 構成要素

- **Pages/Auth/Register.vue**: ページコンポーネント（GuestLayout 使用）
- **Components/Common/ImageUploadField.vue**: アバター画像選択
- **Components/Common/DatePickerDialog.vue**: 生年月日選択

#### ユーザー操作フロー

1. 招待確認ページ（S-014）で「新規登録して参加」を押す
2. 登録ページに参加予定の家族名が表示される
3. 名前・メールアドレス・パスワード（確認）・生年月日（任意）・アバター（任意）を入力する
4. 「登録して参加する」を押す
5. 登録完了と同時に対象家族へ自動参加し、ホーム画面へ遷移する

#### 制約

- セッションに `invite_family_code` がない場合（直接 `/register` アクセス）はログインページへリダイレクト

### S-005: タスク一覧画面

#### 概要

家族グループのタスクをカテゴリー別に一覧表示し、タスクの追加・完了・削除などの操作を行う画面。

#### 構成要素

- **FamilyTask.vue**: タスク一覧のメインコンポーネント
- **TaskListItem.vue**: 個々のタスク行コンポーネント（完了チェック・色表示・メモ）
- **SaveTaskForm.vue**: タスク作成・編集フォーム
- **CategoryManageDialog.vue**: カテゴリー管理ダイアログ起動ボタン
- **ColorChipSelect.vue**: タスクの色選択コンポーネント

#### ユーザー操作フロー（タスク作成）

1. カテゴリーを選択または作成する
2. タスク内容・色・メモを入力する
3. 保存ボタンを押す
4. タスク一覧にリアルタイムで追加される（自分・他のメンバー共に）

#### ユーザー操作フロー（タスク完了）

1. タスクのチェックボックスをタップ/クリックする
2. 完了状態に切り替わる
3. 他のメンバーにもリアルタイムで反映される

#### リアルタイム同期

- Pusherを使ったPrivate Channel `family.{family_id}` で同期
- イベント: `TaskUpdated`、`CategoryUpdated`
- Laravel Echo でフロントエンドがイベントを受信し、Pinia/リアクティブ状態を更新

### S-006: カテゴリー管理ダイアログ

#### 概要

タスクのカテゴリーを管理するダイアログ。作成・編集・削除・並び替えが可能。

#### 構成要素

- **CategoryManageDialog.vue**: カテゴリー一覧表示・操作ボタン
- **CategoryEditDialog.vue**: カテゴリー名編集用サブダイアログ
- **vue-draggable-plus**: ドラッグ＆ドロップ並び替え

#### ユーザー操作フロー（並び替え）

1. カテゴリー管理ダイアログを開く
2. カテゴリー行をドラッグ＆ドロップで並び替える
3. 並び順が自動で保存される（`reorder` API呼び出し）

### S-008: マイページ画面

#### 概要

ユーザーが自身のプロフィールを確認・編集する画面。設定・家族設定へのナビゲーションも提供する。

#### 構成要素

- **EditProfileForm.vue**: 名前・誕生日・アバター画像の編集フォーム
- **ImageUploadField.vue**: 画像アップロードUI（プレビュー付き）
- **DatePickerDialog.vue**: 誕生日選択用日付ピッカーダイアログ

#### ユーザー操作フロー（誕生日変更）

1. 編集ボタンからプロフィール編集フォームを開く
2. 生年月日フィールドをタップ/クリックし、日付ピッカーダイアログを開く
3. カレンダーから日付を選択する（クリアボタンで削除も可能）
4. 保存ボタンを押す
5. マイページに誕生日が反映される（未設定の場合は「未設定」と表示）

#### ユーザー操作フロー（アバター変更）

1. 画像アップロードフィールドをクリックし、画像ファイルを選択する
2. プレビューが表示される
3. 保存ボタンを押す
4. サーバーでWebP形式に変換・リサイズされ保存される
5. 保存成功後、ヘッダーのアバターアイコンも即時更新される（`only: ['user', 'auth']` で共有プロパティを再取得）

#### ユーザー操作フロー（アバター削除）

1. アバター画像の右上に表示される × ボタンを押す
2. プレビューが即時に消える
3. 保存ボタンを押す
4. サーバー側で既存アバターが HStorage・DB の両方から削除される
5. ヘッダーのアバターアイコンがデフォルトアイコン（`mdi-account`）に切り替わる

#### ユーザー操作フロー（設定・家族設定へのナビゲーション）

1. マイページ下部の「設定」カードから「テーマカラー設定」をタップする
2. 設定ページ（S-013）へ遷移する
3. マイページ下部の「家族設定」カードから各メニューをタップする
4. 家族設定変更・メンバー管理・家族切り替えページへ遷移する

### S-013: 設定ページ

#### 概要

ユーザー個別のテーマ・テーマカラーを設定するページ。マイページの「設定」メニューから遷移。

#### 構成要素

- **Pages/MyPage/UserSettings.vue**: ページコンポーネント
- **Components/MyPage/UserSettingsForm.vue**: テーマ・テーマカラー設定フォーム＋アプリショートカット設定への遷移カード

#### ユーザー操作フロー

1. マイページの「テーマカラー設定」をタップする
2. テーマ（ライト/ダーク/システム設定）をセレクトから選択する
3. テーマカラーを7プリセットのカードUI（pink / sunset / ocean / forest / lavender / autumn / midnight）から選択する（各カードにプライマリー・セカンダリー2色プレビュー表示）
4. 「設定を保存」ボタンを押す
5. テーマ・カラーが即時に画面全体へ反映される（`useAppTheme` が `userSettings` の変更を watch して Vuetify のプライマリー・セカンダリー両色へ適用）
6. スナックバーで保存完了の通知が表示される
7. 「アプリショートカット設定」カードをタップすると S-015 へ遷移する

### S-015: アプリショートカット設定ページ

#### 概要

フッターナビゲーションに表示するアプリをユーザーが個別に設定するページ。S-013（設定ページ）から遷移。

#### 構成要素

- **Pages/MyPage/FooterSettings.vue**: ページコンポーネント（`vue-draggable-plus` によるドラッグ並び替え）

#### ユーザー操作フロー

1. 設定ページの「アプリショートカット設定」をタップする
2. 現在フッターに表示されているアプリが一覧表示される（カード形式、ドラッグアイコン付き）
3. ドラッグ＆ドロップで並び替えができる
4. ホームは「固定」チップが表示され削除不可
5. その他のアプリは ✕ ボタンで削除できる
6. 「追加できるアプリ」セクションに未追加のアプリが表示され、タップで追加できる
7. 「保存」ボタンを押すと `POST /mypage/footer-settings` で保存され、スナックバーで通知が表示される

### S-010: 家族設定変更ページ

#### 概要

家族グループの基本情報を変更するページ。マイページの「家族設定」メニューから遷移。

#### 構成要素

- **Pages/MyPage/FamilySettings.vue**: ページコンポーネント（インラインフォーム）
- **Components/Family/RegenerateFamilyCodeDialog.vue**: 家族コード再生成ダイアログ（有効期限選択付き）

#### ユーザー操作フロー

1. マイページの「家族設定変更」をタップする
2. 家族名・最大メンバー数を変更し「保存」を押す
3. スナックバーで保存完了の通知が表示される
4. 家族コード「コードを再生成」ボタンを押すとダイアログが開く

#### 権限

### S-011: メンバー管理ページ

#### 概要

家族の実ユーザーと仮想ユーザーをまとめて管理するページ。

#### 構成要素

- **Pages/MyPage/FamilyMembers.vue**: ページコンポーネント
- **Components/Family/VirtualUserDialog.vue**: 仮想ユーザー追加・編集ダイアログ（アバター画像アップロード付き）
- **Components/Family/InviteBottomSheet.vue**: 招待ロール選択＋メッセージコピー・QR表示のボトムシート
- **Components/Family/InviteQrDialog.vue**: QRコード表示ダイアログ（`qrcode` ライブラリ）
- 除名・仮想ユーザー削除確認は `useConfirmDialog`（`@/Composables/Common/useConfirmDialogService`）を使用

#### ユーザー操作フロー（仮想ユーザー追加）

1. 「仮想メンバーを追加」ボタンを押す
2. ダイアログで名前（必須）・アバター画像（任意）を入力する
3. 「保存」を押す
4. 仮想ユーザー一覧に追加される

#### ユーザー操作フロー（メンバー除名）

1. 除名したいメンバーの「除名」ボタンを押す（オーナーのみ表示）
2. 確認ダイアログが表示される
3. 確認後、メンバーが家族グループから削除される

#### ユーザー操作フロー（招待）

1. 「メンバーを招待する」ボタンを押す
2. ボトムシートが開き、招待ロール（保護者・子ども・メンバー）を選択する
3. **メッセージで招待**: 「招待リンクを送る」を押す → 案内文＋URL がクリップボードにコピーされる → LINE 等に貼り付けて送る
4. **QRコードで招待**: 「QRコードを表示する」を押す → QRコードダイアログが開く → その場でスキャン

#### 招待メッセージ形式

```
〇〇家への招待が届いています！
下記のリンクをタップしてアカウントを作成してください。
https://{ドメイン}/join/{code}?role={role}&signature={sig}
```

#### セキュリティ

- 招待URLはサーバーサイドで `URL::signedRoute()` により署名生成。クライアントでは URL を組み立てない
- `FamilyMemberController::index()` がロール別（parent/child/guest）の署名付き URL を `invite_urls` として props に渡す
- `InviteController::show()` で `signature` パラメータの有無・正当性を検証
  - `signature` あり・有効 → URL 内の `role` をそのまま使用
  - `signature` あり・不正（改ざん） → 無効エラー表示
  - `signature` なし → `role` を無視し `guest` にフォールバック

### S-014: 招待確認ページ

#### 概要

招待URLにアクセスした際に表示される家族参加確認ページ。未ログイン・ログイン済み両方に対応。

#### 構成要素

- **Pages/Auth/JoinFamily.vue**: ページコンポーネント（GuestLayout 使用）

#### ユーザー操作フロー（新規ユーザー）

1. LINE等で受け取った招待URL（`/join/{code}?role={role}&signature={sig}`）にアクセスする
2. 「〇〇家族に参加しませんか？」と家族名・メンバー数・参加ロール（例: 「保護者として参加」）が表示される
3. 「新規登録して参加」ボタンを押す
4. 登録ページ（S-002）へ遷移し、登録完了と同時に指定ロールで家族へ自動参加する

#### ユーザー操作フロー（既存ユーザー）

1. 招待URLにアクセスする
2. 「ログインして参加」ボタンを押す
3. ログインページへ遷移し、ログイン完了後に招待確認ページへ戻る
4. 「この家族に参加する」ボタンを押してホームへ遷移する

#### エラー状態

- **無効コード**: コードが存在しない・期限切れ → エラーメッセージ表示
- **定員超過**: `family.max_members` に達している → 参加ボタン非表示・警告表示
- **参加済み**: すでに対象家族に所属 → 「すでに参加しています」表示

### S-012: 家族切り替えページ

#### 概要

複数の家族グループに所属している場合に、操作対象の家族を切り替えるページ。

#### 構成要素

- **Pages/MyPage/FamilySwitch.vue**: ページコンポーネント（リスト形式、FamilyCard は統合済み）
- アクティブ家族は `CurrentFamilyService`（セッション管理）で管理

#### ユーザー操作フロー

1. マイページの「家族切り替え」をタップする
2. 所属している家族グループの一覧が表示される（現在のアクティブ家族にチェックマーク・`現在` チップ）
3. 切り替えたい家族の行をタップする
4. `POST /families/{family}/switch` が呼ばれ、セッションのアクティブ家族が変更される
5. ホーム画面へリダイレクトされる

## 4. エラーハンドリング方針

| エラー種別              | 表示方法                        | 対応方針                                      |
|------------------------|--------------------------------|----------------------------------------------|
| バリデーションエラー     | フォームフィールド下にエラーメッセージ | Inertia の errors オブジェクトから取得して表示  |
| APIエラー（通信失敗）   | スナックバー（赤色）              | client.ts でキャッチし、SnackbarNotification を表示 |
| 認証エラー（401）       | ログイン画面へリダイレクト         | Laravel/Inertia の認証ミドルウェアで処理       |
| 権限エラー（403）       | スナックバー（赤色）              | 操作不可のフィードバックを表示                 |
