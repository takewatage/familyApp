## 2. 各画面・機能の詳細

### S-005: タスク一覧画面

#### 概要

家族グループのタスクをカテゴリー別に一覧表示し、タスクの追加・完了・削除などの操作を行う画面。

#### 構成要素

- **FamilyTask.vue**: タスク一覧のメインコンポーネント
- **TaskListItem.vue**: 個々のタスク行コンポーネント（完了チェック・色表示・メモ）
- **SaveTaskForm.vue**: タスク作成・編集フォーム
- **CategoryManageDialog.vue**: カテゴリー管理ダイアログ起動ボタン
- **ColorChipSelect.vue**: タスクの色選択コンポーネント

#### ユーザー操作フロー（タスク作成）

1. カテゴリーを選択または作成する
2. タスク内容・色・メモを入力する
3. 保存ボタンを押す
4. タスク一覧にリアルタイムで追加される（自分・他のメンバー共に）

#### ユーザー操作フロー（タスク完了）

1. タスクのチェックボックスをタップ/クリックする
2. 完了状態に切り替わる
3. 他のメンバーにもリアルタイムで反映される

#### リアルタイム同期

- Pusherを使ったPrivate Channel `family.{family_id}` で同期
- イベント: `TaskUpdated`、`CategoryUpdated`
- Laravel Echo でフロントエンドがイベントを受信し、Pinia/リアクティブ状態を更新

### S-006: カテゴリー管理ダイアログ

#### 概要

タスクのカテゴリーを管理するダイアログ。作成・編集・削除・並び替えが可能。

#### 構成要素

- **CategoryManageDialog.vue**: カテゴリー一覧表示・操作ボタン
- **CategoryEditDialog.vue**: カテゴリー名編集用サブダイアログ
- **vue-draggable-plus**: ドラッグ＆ドロップ並び替え

#### ユーザー操作フロー（並び替え）

1. カテゴリー管理ダイアログを開く
2. カテゴリー行をドラッグ＆ドロップで並び替える
3. 並び順が自動で保存される（`reorder` API呼び出し）

### S-008: マイページ画面

#### 概要

ユーザーが自身のプロフィールを確認・編集する画面。

#### 構成要素

- **EditProfileForm.vue**: 名前・誕生日・アバター画像の編集フォーム
- **ImageUploadField.vue**: 画像アップロードUI（プレビュー付き）
- **DatePickerDialog.vue**: 誕生日選択用日付ピッカーダイアログ

#### ユーザー操作フロー（誕生日変更）

1. 編集ボタンからプロフィール編集フォームを開く
2. 生年月日フィールドをタップ/クリックし、日付ピッカーダイアログを開く
3. カレンダーから日付を選択する（クリアボタンで削除も可能）
4. 保存ボタンを押す
5. マイページに誕生日が反映される（未設定の場合は「未設定」と表示）

#### ユーザー操作フロー（アバター変更）

1. 画像アップロードフィールドをクリックし、画像ファイルを選択する
2. プレビューが表示される
3. 保存ボタンを押す
4. サーバーでWebP形式に変換・リサイズされ保存される

## 4. エラーハンドリング方針

| エラー種別              | 表示方法                        | 対応方針                                      |
|------------------------|--------------------------------|----------------------------------------------|
| バリデーションエラー     | フォームフィールド下にエラーメッセージ | Inertia の errors オブジェクトから取得して表示  |
| APIエラー（通信失敗）   | スナックバー（赤色）              | client.ts でキャッチし、SnackbarNotification を表示 |
| 認証エラー（401）       | ログイン画面へリダイレクト         | Laravel/Inertia の認証ミドルウェアで処理       |
| 権限エラー（403）       | スナックバー（赤色）              | 操作不可のフィードバックを表示                 |
